# ai-dev-toolkit

AI development toolkit featuring prompts, rules, and configurations for Claude Code to boost productivity.

## Skills

| Skill | 描述 |
| --- | --- |
| [commit](skills/commit/SKILL.md) | 根据 git diff 生成符合规范的 commit message |
| [changelog](skills/changelog/SKILL.md) | 写 changelog、更新版本日志、整理版本变更记录 |
| [unit-test](skills/unit-test/SKILL.md) | 编写单元测试 |
| [ddl-sql](skills/ddl-sql/SKILL.md) | 编写 MySQL DDL 建表/改表语句 |
| [markdown](skills/markdown/SKILL.md) | 写 Markdown |
| [translate](skills/translate/SKILL.md) | 将文档翻译为中文 |
| [humanize](skills/humanize/SKILL.md) | 去除文本中的 AI 生成痕迹，使文字更自然 |
| [research](skills/research/SKILL.md) | 调研框架/类库/技术方案，探讨技术选型 |
| [skill-dev](skills/skill-dev/SKILL.md) | 创建或更新 skill 的指导手册 |
